# Créditos — ícones em assets/ui-icons/

Silhuetas pixeladas (32×32) geradas por `tools/build_icons.cjs` a partir do
**game-icons.net** (https://github.com/game-icons/icons, pacote npm
`@iconify-json/game-icons`), sob **Creative Commons Attribution 3.0**
(https://creativecommons.org/licenses/by/3.0/). Foram redimensionadas e
convertidas em máscara de um pixel de cor (alterações feitas por este projeto).

Ícones feitos por (conforme a pasta de cada ícone no repositório original):

- Lorc — http://lorcblog.blogspot.com (56 ícones usados)
- Delapouite — http://delapouite.com (49)
- Skoll (4), Lucas (2), Sbed — http://opengameart.org/content/95-game-icons (2),
  DarkZaitzev — http://darkzaitzev.deviantart.com (3), Willdabeast —
  http://wjbstories.blogspot.com (1), Zeromancer (1, CC0) e "various artists" (1)

Lista de qual ícone é usado onde: `tools/icons.json`.
