# Logos (opcionais)

Coloque aqui dois PNG com fundo transparente. Se o arquivo não existir, o jogo usa o texto no lugar.

- `publisher.png` — logo da publicadora (Javali Torto Games), aparece no começo. Ideal: ~1200×800.
- `logo.png` — logo do jogo (Hearthblade), aparece na tela de título. Ideal: ~1600×700. **Sem o subtítulo**: o "TACTICAL FORGE" é escrito pelo jogo, embaixo.

Prompts sugeridos: ver `BRAND.md` na pasta do jogo.
