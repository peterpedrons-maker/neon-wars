# Créditos — molduras, botões e barras em assets/rpgui/

Imagens do **RPGUI** (https://github.com/RonenNess/RPGUI, Ronen Ness), licença
**zlib** (ver LICENSE.txt). Os gráficos do tema padrão são de domínio público,
feitos por "Buch". Usadas aqui só como imagens (molduras 9-slice, botões e
barra de progresso) com CSS próprio do jogo; `bar-frame.png` é a junção das
peças esquerda/trilho/direita da barra de progresso, feita por este projeto.

As imagens deste diretório foram **recoloridas** (paleta "couro"; botões dourados em ouro mais sóbrio) por
`tools/recolor_rpgui.py` a partir dos originais do pacote npm `rpgui@1.0.3` — alterações plenamente marcadas
conforme a licença zlib; os arquivos originais não estão no repositório.
